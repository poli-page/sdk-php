Every failure thrown by the SDK is a `PoliPage\PoliPageException` (which extends `RuntimeException`). The `errorCode` property tells you what went wrong; the `requestId` property is what to quote when filing a support ticket. Specialized subclasses under `PoliPage\Exception\*` let you `catch` by HTTP status family.

The predicates read `status` and `errorCode`, the same in every Poli Page SDK: `isAuthError()` is `status` 401 or 403, `isRateLimitError()` 429, `isValidationError()` 400, `isNetworkError()` is `errorCode` `network_error` or `timeout`, and `isRetryable()` is a network error, a timeout, a 5xx or a 429, except `QUOTA_EXCEEDED`, `OVERAGE_CAP_EXCEEDED` and `STORAGE_ACCESS_DENIED`; a `DOWNLOAD_FAILED` is never retryable, whatever the storage status. A `DOWNLOAD_FAILED` carries the storage's status, so a 403 from storage is an auth error.

## The exception class

```php
use PoliPage\PoliPageException;
use PoliPage\RenderInput;

try {
    $client->render->pdf(new RenderInput(
        project: 'billing',
        template: 'invoice',
        data: ['invoiceNumber' => 'INV-001'],
    ));
} catch (PoliPageException $e) {
    error_log(sprintf('%s %s — %s', $e->errorCode, $e->requestId ?? '', $e->getMessage()));
    throw $e;
}
```

## Example

```php
<?php

require __DIR__ . '/vendor/autoload.php';

use PoliPage\Exception\RateLimitException;
use PoliPage\PoliPage;
use PoliPage\PoliPageException;
use PoliPage\RenderInput;

$client = PoliPage::client($_ENV['POLI_PAGE_API_KEY']);

try {
    $pdf = $client->render->pdf(new RenderInput(
        project: 'billing',
        template: 'invoice',
        data: ['invoiceNumber' => 'INV-001'],
    ));
} catch (RateLimitException $e) {
    // RATE_LIMIT_EXCEEDED outlasted the retries, or QUOTA_EXCEEDED /
    // OVERAGE_CAP_EXCEEDED, which the SDK never retries: queue the job for later.
    sleep(30);
    throw $e;
} catch (PoliPageException $e) {
    throw $e;
}
```
